# 수학 구조 튜터 (Flutter Prototype)

중·고등학생용 미분/적분 학습 앱 프로토타입입니다.

## 학습 흐름
문제 → 구조 힌트(핵심 빨간색) → 서술형 힌트 → 체계적 풀이 → 요약 정리 → 다음 문제 → 10문제 후 단원 정리

## 실행
1. Flutter SDK 설치
2. 이 폴더에서 `flutter pub get`
3. `flutter run`

현재 버전은 서버/AI 없이 10문제를 앱 내부 데이터로 동작시키는 MVP입니다. 이후 문제은행(JSON/Firebase), 학생 답안 입력, AI 힌트 생성, 학습 기록 저장 기능을 연결할 수 있습니다.
